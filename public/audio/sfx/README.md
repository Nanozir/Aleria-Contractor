# Casino sound effects (optional)

Drop recorded `.ogg` files here to replace the synthesized casino sounds. Missing files fall back to synthesized sounds automatically.

| File | Used for |
|---|---|
| `card_shuffle.ogg` | Shuffling the shoe or deck |
| `card_deal.ogg` | Dealing a card |
| `card_flip.ogg` | Turning a card face up |
| `chips.ogg` | Placing bets and payouts |
| `dice_shake.ogg` | Shaking dice |
| `dice_throw.ogg` | Dice landing |

A good free source is Kenney's **Casino Audio** pack (CC0 licence, no credit required): https://kenney.nl/assets/casino-audio. Rename the files you pick to the names above.
